## Responsive Design

The portfolio is designed for desktop, tablet, and mobile devices.

Desktop includes a two-column hero, bounded content width, project grid, horizontal navigation, language switcher, and hover interactions.

Mobile adapts to a single-column layout with a mobile navigation menu, mobile language selector, responsive buttons, proportional images, and touch-friendly interactions.

Mouse-based effects are reduced or disabled on touch devices.

## Getting Started

This project uses plain HTML, CSS, and JavaScript, so no build process is required.

### Clone the repository

```bash
git clone https://github.com/sandrianto07/portfolio.git
```

### Open the project

```bash
cd portfolio
```

Then open `index.html` in your browser.

For development, you can use **Live Server** in Visual Studio Code.
